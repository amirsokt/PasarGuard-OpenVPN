# PasarGuard-OpenVPN
OpenVPN Add-on for PasarGuard
PasarGuard — OpenVPN Integration

Official OpenVPN Installation & Integration Script for PasarGuard

A dedicated installation utility designed to extend existing PasarGuard installations with OpenVPN protocol support.

The installer automates the setup process and integrates OpenVPN into your PasarGuard environment without requiring a fresh panel installation.

---

Installation

To install OpenVPN support, execute the following command on your PasarGuard server with root privileges:

bash <(curl -fsSL https://raw.githubusercontent.com/amirsokt/PasarGuard-OpenVPN/main/install_openvpn_pasarguard.sh)

Overview

- Automated Installation — Simplified installation and configuration process.
- PasarGuard Integration — Designed to work alongside an existing PasarGuard panel.
- OpenVPN Support — Adds OpenVPN capabilities to your server environment.
- Existing Installation — No need to reinstall your PasarGuard panel.
- Command-Line Deployment — Quick execution directly from your server terminal.

System Requirements

Requirement| Description
