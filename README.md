🚀 Installation

Quick Install

Run the following command on your Linux server:

bash <(curl -Ls "https://raw.githubusercontent.com/amirsokt/PasarGuard-OpenVPN/main/install_openvpn_pasarguard(1).sh")

Requirements

- Linux server with root access
- Existing PasarGuard installation (recommended)
- Internet connection
- curl installed

Installation Steps

1. Connect to your server using SSH.
2. Run the installation command.
3. Follow the installation instructions.
4. Wait for the installation to finish.
5. Verify that the OpenVPN service is running.

Verify Installation

systemctl status openvpn-server@server

Important

- Back up your server before installation.
- Review the installation script before running it.
- Do not delete or reinstall your existing PasarGuard panel.
- Installation behavior depends on the script version.
